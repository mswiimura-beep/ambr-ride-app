かんたん説明書

走る前も、途中も、帰ってからも。スマートフォンだけで仲間と情報を共有できます。

AMBRアプリを開く
最初に覚えるのは2つだけです。
迷ったら画面下の「メニュー」。写真や場所を送るときは、メニューの「みんなと共有」を押します。

1．初めて開くとき

  1. 「AMBRアプリに入る」を押します。
  2. 見るだけなら、そのままで大丈夫です。
  3. 投稿や参加をするときは、右上の丸いボタンから名前とアイコンを登録します。

登録した名前とアイコンは、このスマートフォンに保存されます。

2．写真・場所・コメントを共有する

  1. メニュー上部の「みんなと共有」を押します。
  2. 場所・店の名前を入力して、出てきた候補を一覧か地図から選びます。現在地も選べます。
  3. コメントを入力します。
  4. 写真欄を押し、写真ライブラリ、カメラ、ファイルから写真を選びます。写真は一度に最大5枚です。
  5. 「みんなと共有する」を押します。
運転中は操作しないでください。安全な場所へ停車してから投稿してください。通信できない場合は送信待ちになり、通信が戻ったときに再送されます。

3．イベントを作る

  1. メニューの「イベントカレンダー」を押します。
  2. 「＋ イベント」を押します。
  3. イベント名、日付、時刻を入力します。
  4. 集合場所・店名を検索し、候補を一覧か地図から選びます。
  5. 必要なら持ち物や雨天時の案内を書き、「イベントを共有する」を押します。

イベント、集合場所、参加者はAMBRアプリの利用者に共有されます。

4．イベントへ参加・途中合流する

  1. カレンダーからイベントを開き、「参加・合流予定を登録」を押します。
  2. 集合場所から参加 または 途中で合流 を選びます。
  3. 途中合流の場合は、合流予定時刻と場所を登録します。
  4. 保存すると、誰が・何時頃・どこで合流するかが地図と参加者欄に表示されます。

予定が変わったときは、同じボタンから変更または参加取り消しができます。

5．Googleマップのルートを記録に入れる

  1. 「自分のツーリング記録」を開きます。
  2. Googleマップで出発地と目的地を設定し、「共有」→「リンクをコピー」を押します。
  3. AMBRの入力欄へ貼り付け、「ルートを確認」を押します。
  4. 店・施設だけのリンクを貼った場合は、「出発地」へ青森駅などを入力して、もう一度確認します。
  5. 距離と推定時間が入った記録画面で、日付などを確認して「記録を保存する」を押します。
成功の目印：「Googleマップの予定ルートを読み込みました」と表示され、記録入力画面が開きます。URLを貼り付けただけでは保存されません。最後に「記録を保存する」を押してください。

3Dで見て動画にする

  1. ルート付き記録の「見る」を押します。
  2. 「3D再生する」を押します。
  3. 15秒・30秒・60秒から再生時間を選び、「最初から再生」を押します。
  4. 動画にするときは「動画を保存」を押し、作成が終わるまで画面を開いたまま待ちます。
  5. 「完成した動画を保存」に変わったら、もう一度押して保存先を選びます。

Googleマップのリンクから作った経路は、これから走る「予定ルート」です。Googleマップの道路状況などにより、実際に走った道と少し異なる場合があります。

動画を作っている間は、画面を閉じたりブラウザを背景へ移したりしないでください。端末が動画作成に対応していない場合は、3D再生を始めてiPhoneの「画面収録」を使います。

6．ほかにできること

みんなの投稿

仲間が共有した写真、場所、コメントを見られます。

今日・明日の天気

メニュー上部に現在地周辺の今日・明日の予報が表示されます。天気欄を押すと7日間の最高・最低気温、降水確率、風速を確認できます。位置情報を許可しない場合は青森市の予報を表示します。

自分の走行マップ

この端末のツーリング記録へ保存したルートを重ねて、自分の記録を確認できます。

みんな＋自分の軌跡

仲間が共有したルートと自分の保存ルートを重ね、走った方向やよく使う道を比べられます。

自分のツーリング記録

Googleマップの経路リンク、または店・施設の場所リンクから予定ルートを作り、推定距離・推定時間と一緒に保存できます。

予定ルートは共有された出発地・経由地・目的地をもとに再計算するため、Googleマップの表示と少し違う場合があります。保存する前にルート、距離、時間を確認してください。

ルートがないツーリングは「＋ 記録する」から日付、場所、一緒に走った人、コメント、写真を手入力できます。

7．困ったとき

メニューに戻れない

画面下の「メニュー」、画面上の「← メニュー」、または左上のAMBRロゴを押します。ブラウザの戻る操作も使えます。

写真を選べない

写真欄そのものを押してください。iPhoneでは「写真ライブラリ」「写真を撮る」「ファイルを選択」が表示されます。写真へのアクセス確認が出たら許可します。

場所が出ない

店名だけで見つからないときは、市町村名も一緒に入力してください。例：青森市 浅虫温泉駅

3D動画を保存できない

動画が完成して「完成した動画を保存」と表示されたら、そのボタンをもう一度押してください。作成中に画面を閉じた場合は、最初からやり直します。直接保存に対応していない端末では、iPhoneの「画面収録」を使ってください。

地図や投稿が表示されない

電波を確認し、ページを再読み込みしてください。ブラウザを背景にしたままでは送信が止まる場合があるため、完了表示までは画面を開いておくと確実です。

8．安全とプライバシー

公開URLを知っている人はアプリを開けます。自宅住所、電話番号、ナンバープレート、待ち合わせに不要な個人情報は投稿しないでください。

写真を共有する前に、写っている人へ確認しましょう。自分の投稿や参加予定は、自分の端末の利用者情報から変更・削除できます。
