かんたん説明書

走る前も、途中も、帰ってからも。スマートフォンだけで仲間と情報を共有できます。

AMBRアプリを開く
迷ったら画面下の「メニュー」。
「イベントを作成」「イベントを見る」「Googleマップルート」「ツーリングを記録」の4つから、いま行いたい操作を選びます。

1．初めて開くとき

  1. 「AMBRアプリに入る」を押します。
  2. 見るだけなら、そのままで大丈夫です。
  3. 投稿・コメント・リアクションを初めて使うときは、画面の案内からメール本人確認を行います。

登録した名前とアイコンは、このスマートフォンに保存されます。

2．写真・場所・コメントを共有する

本人確認前にこの操作を押すと、その場で「投稿できるようにする」画面が開きます。

  1. メニューの「写真・場所を仲間に送る」を押します。
  2. 場所・店の名前を入力して、出てきた候補を一覧か地図から選びます。現在地も選べます。
  3. コメントを入力します。
  4. 「写真ライブラリ・ファイル」または「カメラで撮る」から写真を追加します。何回かに分けても合計5枚まで選べ、選択後は写真全体を確認できます。
  5. 「みんなと共有する」を押します。
運転中は操作しないでください。安全な場所へ停車してから投稿してください。通信できない場合は送信待ちになり、通信が戻ったときに再送されます。

3．イベントを作る

  1. メニューの「イベントを作成」を押します。
  2. イベント名、日付、時刻を入力します。
  3. 集合場所・店名を入力します。候補や地図のピンを選ぶ必要はありません。
  4. 必要ならGoogleマップでコースを作り、共有リンクを貼ります。リンクは変換せず、そのまま仲間に共有されます。
  5. 持ち物や雨天時の案内を書き、「イベントを共有する」を押します。

イベント、集合場所、参加者はAMBRアプリの利用者に共有されます。

自分が作ったイベントは、詳細画面から内容・集合場所・コースを編集したり、削除したりできます。保存に失敗した場合は入力が残るので、通信状態を確認して「もう一度保存する」を押してください。

4．イベントへ参加・途中合流する

  1. カレンダーからイベントを開き、「参加・合流予定を登録」を押します。
  2. 集合場所から参加 または 途中で合流 を選びます。
  3. 途中合流の場合は、合流予定時刻と場所を登録します。
  4. 保存すると、誰が・何時頃・どこで合流するかが参加者欄に表示されます。

予定が変わったときは、同じボタンから変更または参加取り消しができます。

5．Googleマップのルートを記録に入れる

  1. 「自分のツーリング記録」を開きます。
  2. 「Googleマップを開いてルートを作る」を押し、出発地と目的地を設定します。
  3. Googleマップで「共有」→「リンクをコピー」を押し、AMBRへ戻ります。
  4. AMBRの入力欄へ貼り付け、「ルートを確認」を押します。
  5. 店・施設だけのリンクを貼った場合は、「出発地」へ青森駅などを入力して、もう一度確認します。
  6. 距離と推定時間が入った記録画面で日付などを確認し、「自分の記録に保存する」か「保存して、みんなにも共有」を押します。
成功の目印：「Googleマップの予定ルートを読み込みました」と表示され、記録入力画面が開きます。URLを貼り付けただけでは保存されません。自分だけで使うか、みんなにも共有するかを最後に選んでください。

保存後に記録の「見る」を押すと、道路名や市町村が分かる地図上にルート、出発地、到着地を表示します。地図は指で拡大・縮小・移動できます。

実際に走ったGPXを読み込む・書き出す

  1. 「自分のツーリング記録」の「GPXを読み込む」を押します。
  2. ナビやGPS記録アプリから保存したGPXファイルを選びます。
  3. 距離・日時を確認し、「自分の記録に保存する」か「保存して、みんなにも共有」を押します。
  4. 保存した経路を取り出すときは、一覧上部の「保存済みGPXを書き出す」、または記録の「見る」から「この記録のGPXを書き出す」を押します。

GPSファイルから読み込んだ線は「実走ルート」、Googleマップから作った線は「予定ルート」として保存されます。

Googleマップのリンクから作った経路は、これから走る「予定ルート」です。Googleマップの道路状況などにより、実際に走った道と少し異なる場合があります。

6．ほかにできること

みんなの投稿

本人確認前でも、仲間が共有した写真、場所、コメントを見られます。投稿カードは左側が地図、右側が代表写真2枚です。地図を押すと大きな地図、写真を押すと全写真の一覧と拡大表示が開きます。

メール本人確認が完了すると、自分の投稿に「編集」と「削除」が表示されます。編集では場所・コメント・写真を変更でき、写真は残すものと新しく追加するものを合わせて5枚までです。保存・削除はサーバー上の投稿データを確認できた時だけ完了として表示します。

本人確認後は、投稿の下で「いいね」「いい写真」「行ってみたい」を押して反応できます。「コメント」を開くと、全員が仲間のコメントを読めます。自分が送ったリアクションはもう一度押すと取り消せ、自分のコメントは削除できます。

今日・明日の天気

メニュー上部に現在地周辺の今日・明日の予報が表示されます。天気欄を押すと7日間の最高・最低気温、降水確率、風速を確認できます。位置情報を許可しない場合は青森市の予報を表示します。

自分の走行マップ

この端末のツーリング記録へ保存したルートを重ねて、自分の記録を確認できます。

みんな＋自分の軌跡

仲間が共有したルートと自分の保存ルートを地図タイル上に重ねて確認できます。自分はオレンジ、ほかの人は青、実走は実線、予定は破線です。「光を流す」を押すと登録された走行方向を再生します。「みんなのマップに共有する」の完了後は、同じボタンが「共有済み・みんなのマップで確認」に変わります。

自分のツーリング記録

Googleマップの経路リンク、または店・施設の場所リンクから予定ルートを作り、推定距離・推定時間と一緒に保存できます。

予定ルートは共有された出発地・経由地・目的地をもとに再計算するため、Googleマップの表示と少し違う場合があります。保存する前にルート、距離、時間を確認してください。

ルートがないツーリングは「＋ 記録する」から日付、場所、一緒に走った人、コメント、写真を手入力できます。

記録を編集する

記録の「見る」から「記録を編集する」を押すと、ツーリング名、日付、場所、一緒に走った人、コメント、写真を変更できます。共有済みルートの名称や日付も同時に更新します。写真は全体が見える表示になり、押すと拡大できます。

記録を削除する

削除したい記録の「見る」を押し、画面下の「この記録を削除」を押します。確認画面で削除すると、端末に保存した写真・GPXも消えます。「みんなのマップ」に共有済みのルートは、共有先からも削除されます。

7．困ったとき

メニューに戻れない

画面下の「メニュー」、画面上の「← メニュー」、または左上のAMBRロゴを押します。ブラウザの戻る操作も使えます。

写真を選べない

写真欄そのものを押してください。iPhoneでは「写真ライブラリ」「写真を撮る」「ファイルを選択」が表示されます。写真へのアクセス確認が出たら許可します。

場所が出ない

店名だけで見つからないときは、市町村名も一緒に入力してください。例：青森市 浅虫温泉駅

Googleマップの短縮リンクを開けない

画面に表示された理由を確認してください。「HTTP 404」や「短縮リンクを展開できません」と出た場合は、古いリンクや途中で切れたリンクの可能性があります。Googleマップで経路を開き直し、「共有」から新しいリンクをコピーしてください。

地図や投稿が表示されない

電波を確認し、ページを再読み込みしてください。ブラウザを背景にしたままでは送信が止まる場合があるため、完了表示までは画面を開いておくと確実です。

投稿が「送信待ち」になった

写真付き投稿だけは端末に一時保存され、通信が戻ると再送されます。「もう一度送る」で手動再送でき、不要なら「送信待ちを削除」で端末から取り消せます。イベントやコメントは入力画面を閉じず、通信が戻ってからもう一度送信してください。

8．安全とプライバシー

公開URLを知っている人はアプリを開けます。自宅住所、電話番号、ナンバープレート、待ち合わせに不要な個人情報は投稿しないでください。

写真を共有する前に、写っている人へ確認しましょう。自分の投稿や参加予定は、自分の端末の利用者情報から変更・削除できます。

共有データの所有者確認には、このブラウザに保存された匿名の利用者情報を使います。ブラウザのサイトデータを消したり別の端末へ替えたりすると、以前の投稿やイベントを自分で削除できなくなる場合があります。
